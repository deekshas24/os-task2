   the Dining Philosophers problem and the monitor solution using a state array and condition variables.

3. Oracle, "Interface Condition", *Java SE 17 API Documentation*.
   https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/concurrent/locks/Condition.html
4. A. B. Downey, *The Little Book of Semaphores*, 2nd ed., Green Tea Press, 2016.
   https://greenteapress.com/wp/semaphores/ (Section 4.2 Readers–writers, including the no-starve turnstile
   solution; Section 4.4 Dining philosophers, including the "footman" limiting the table to n−1).
