# OS-Synchronization-Assignment

Java 17+ implementations of classic OS synchronization problems.

## Structure
- `readers_writers/semaphore/` – Readers–Writers using semaphores
- `readers_writers/monitor/` – Readers–Writers using monitors
- `dining_philosophers/semaphore/` – Dining Philosophers using semaphores
- `dining_philosophers/monitor/` – Dining Philosophers using monitors
- `common/` – Shared utilities
- `generated_html/` – Generated HTML output
- `screenshots/` – Run screenshots
- `ai_prompts/prompts.md` – AI prompts used
- `references/references.md` – References
- `report/` – Final report

## Requirements
Java 17 or later.
